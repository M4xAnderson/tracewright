# Scan: attributes are stated by the user, suppressions carry a disposition, and every rule runs on its own supervised thread

Amends ADR 0012. A relationship's **interaction** (synchronous or asynchronous) and **timeout** are attributes the user states; port bindings never set them, because deriving them makes request/reply pairs look like synchronous cycles or locks waiting callers to asynchronous. An attribute the model does not give is **not stated**, never a default; a rule that needs it reports Not checkable and names the missing data. Cloud-kind defaults, when those kinds arrive, form a separate "assumed" tier, never plain stated values. A **suppression** has a disposition, *accepted* (the finding is real) or *not real* (the rule is wrong here), with a written reason and a date; it is a Command, so it is undoable and journaled. Severities are High and Medium. Persons are the only entry points of the single-point-of-failure rule in v1, and that rule ships in slice 5 only if the E8 dry run finds a real single point of failure with replicas and zones statable for most required units. Duplicate no-timeout findings for one call drawn at two levels are reported each and counted in E8. The scan runs on an explicit command in slice 5, with **one supervised thread per rule** (`scan-<n>-<rule-id>`, within ADR 0012's `scan-*` prefix), so a rule panic becomes an "internal error" entry for that rule without `catch_unwind`; a scan can be cancelled; findings carry the scan input hash and render stale when it differs.

## Considered Options

- **Interaction derived from bindings:** E5 case 1 (request/reply) becomes a cycle finding, E5 case 3 cannot express a waiting caller over an asynchronous binding.
- **One thread for the whole scan:** one panicking rule loses every finding, or needs `catch_unwind`.
- **Many dispositions (Threat Dragon):** the noise guardrail needs only "real and accepted" versus "not real".

## Consequences

- `docs/specs/scan-rules.md` §2, §3.9, §12, `docs/design/design.md` §4 and `docs/specs/decisions.md` D-18, D-27 carry the rules.
